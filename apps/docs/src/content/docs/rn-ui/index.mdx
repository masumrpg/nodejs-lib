`@masumdev/rn-ui` is a feature-rich, high-performance UI library designed specifically for React Native and Expo monorepos. Built with pure TypeScript, design tokens, and smooth Reanimated worklets.

## Features

<CardGrid>
  <Card title="63 Production Primitives" icon="laptop">
    From basic Buttons and Avatars to complex Calendars, Comboboxes, ContextMenus, and Spinners.
  </Card>
  <Card title="Typed Design System & Tokens" icon="setting">
    Unified base interface contract (ToneProps, VariantProps, BaseGlassProps) and 100% theme token consumption.
  </Card>
  <Card title="Zero-Bounce Fluid Worklets" icon="star">
    Critically damped spring physics and cubic curves executing 100% on the UI thread without bridge lag.
  </Card>
  <Card title="Dark Mode & Versatile Styling" icon="moon">
    Built-in dark mode and versatile layouts: Spotify-style borderless, outlined flat, elevated shadows, and glassmorphism.
  </Card>
</CardGrid>
